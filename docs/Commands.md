# Synapse Commands

A Command is a structured instruction generated by the AI.

The Action Engine never receives raw natural language.

Example

User:

Set an alarm for tomorrow at 6 AM.

↓

Command

{
  "skill": "clock",
  "action": "set_alarm",
  "parameters": {
    "time": "06:00",
    "date": "tomorrow"
  }
}

---

## Command Format

{

  "action": "",
